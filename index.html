Practise your new Anki words in sentences

Each day this site shows the new words from your Anki deck. You write sentences with each word, and an AI tutor (DeepSeek) marks mistakes in three colours: how you used the new word, grammar, and naturalness, then explains them in English. You can ask follow-up questions about every correction.

Setup takes about five minutes: upload your deck, choose where you are in it, and add a DeepSeek API key. Your deck, progress and key stay in this browser.

1 · Vocabulary list

  1. In Anki on your computer, open File → Export…
  2. Export format: Notes in Plain Text (.txt). Include: your deck.
  3. Untick Include HTML and media references, then export and upload the file here.

After uploading, check that each field below points to the right column. The preview shows the first rows. Any tab- or comma-separated word list works too.

2 · Daily plan

The block of words moves forward on the next calendar day only after you press “Done for today”, so a skipped day doesn’t put you out of step with Anki.

3 · DeepSeek API key

  1. Sign up at platform.deepseek.com.
  2. Top up a small amount (the minimum lasts months: one check costs a fraction of a cent).
  3. Open API keys, create a key, and paste it here.

The key is saved only in this browser and sent only to DeepSeek (api.deepseek.com), never to this website’s server. Anyone who can use this browser could read it, so keep only a small balance on the account.

Have a passphrase from the site owner instead?

With the owner’s passphrase you can use their key without a DeepSeek account. Leave the API key field empty to use it.

Backup

Your list, progress and past attempts live in this browser. Export them to move to another device (your API key and passphrase are not included).
